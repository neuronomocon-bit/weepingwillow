Approved Book 2 chapter files are saved here after review (parallels Book 1's `chapters/` folder).

**These files are the single source of truth.** Every correction goes here and only here. `chapter_review.md` is a staging file holding one chapter at a time and is cleared on approval — it is not an accumulating manuscript. To read the book straight through, run `node build-manuscript.js` and read the artifact; never hand-edit it.

**Book 2 is a sequel** (second pivot, 2026-08-26). It opens weeks after The Absence and the origin arrives as seven dramatized Marin chapters that Iris recovers off Meridian's drives.

- Outline: `series-bible/06-book2-outline.md`
- Briefs: `series-bible/08-book2-chapter-briefs.md`
- Decisions: `series-bible/13-arc-revision.md`
- Progress: `review-progress.md`

**Book 2 is titled "The Ending"** (set 2026-08-27). "The Keeping" was chosen for the prequel and was retired with it.

**Filenames are `NN-slug.md` where NN is the chapter number in the final structure.** Numbering is expected to be sparse while drafting is in progress; the build script warns on gaps so a missing chapter cannot silently vanish from an export.

Both superseded arcs — "The Hunger" and the prequel — are archived in `series-bible/archive/` with a README explaining what moved where.
