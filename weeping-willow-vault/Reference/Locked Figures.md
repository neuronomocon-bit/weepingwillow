# Locked Figures
**The numbers and strings that must never drift.**

> [!warning] One figure per rendering
> A draft had *"five months"* naming two different intervals in one chapter, and **both were
> arithmetically correct.** And **check that a number still means what it meant in the chapter
> it came from** — Ch7's *population* escalation intervals were once used as *individual*
> return intervals, then quoted as a return window. See [[Audit Method]].
